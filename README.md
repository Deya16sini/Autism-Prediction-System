# Autism-Prediction-System
This project predicts the likelihood of Autism Spectrum Disorder (ASD) using machine learning techniques. It analyzes behavioral and screening test features from a dataset to help identify potential autism indicators.

## 📌 Description
A machine learning-based autism prediction system built with Python and Jupyter Notebook. The model uses screening test attributes and demographic features to classify whether an individual may have Autism Spectrum Disorder (ASD).

## ✅ Features
- Predicts autism likelihood using screening test data  
- Data preprocessing and cleaning of the dataset  
- Exploratory Data Analysis (EDA) to understand feature relationships  
- Machine learning model for classification  
- Visualization of important factors influencing predictions  

## 🛠️ Tools Used
- **Python** for implementation  
- **Pandas** & **NumPy** for data handling  
- **Matplotlib / Seaborn** for visualization  
- **Scikit-learn** for machine learning algorithms  
- **Jupyter Notebook** for development and experimentation  

## ⚙️ How It Works
1. The autism screening dataset is loaded and cleaned.  
2. Relevant behavioral and demographic features are selected.  
3. Exploratory Data Analysis is performed to understand patterns.  
4. Data is converted into numerical format for machine learning.  
5. A classification model is trained on the dataset.  
6. The trained model predicts the likelihood of autism for new inputs.
